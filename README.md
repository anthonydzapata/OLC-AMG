# OLC — Content Operations Dashboard

A single-page content operations dashboard for **The Old Line Company**.

## Live Demo

Once deployed via GitHub Pages, this dashboard will be available at:
`https://<your-github-username>.github.io/<repo-name>/`

## What's Inside

A self-contained `index.html` file with no build step required — pure HTML + CSS + vanilla JS. Tracks:

- **Production Pipeline** — assets across Idea / Brief / Production / Review stages
- **Brief Builder** — create new content briefs
- **Inspo Log** — capture inspiration
- **The Thread** — internal team notes

## How to Deploy on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under "Source", select **Deploy from a branch**
4. Choose branch `main` and folder `/ (root)`
5. Click **Save** — your live URL appears within ~1 minute

## Local Use

Just open `index.html` in any browser. No installation needed.
